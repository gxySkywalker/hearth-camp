# 开发脚本索引

| 目录 | 内容 |
| --- | --- |
| `art/` | 美术草稿准备、图集归一化、底图处理与像素接缝检查 |
| `quality/` | 美术资源校验、邮局生命周期与 AI 信件检查 |
| `maintenance/` | 本地维护工具；图标生成脚本只会写入 `assets/branding/generated-icon-draft.png`，不会覆盖正式应用图标 |
| 根目录 | 仅保留暂停的小镇草稿生成脚本，未经明确授权不得运行或移动 |

常用命令统一写在根目录 `package.json` 的 `scripts` 中；不要直接猜测脚本路径。
