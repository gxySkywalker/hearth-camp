# 炉火营地文档索引

这里记录产品与世界的已确认事实。开发前先阅读本索引，再按需求进入对应模块；任何实现不得绕过世界圣经、伙伴冻结规则或正式交接边界。

## 文档分类

| 目录 | 内容 | 使用时机 |
| --- | --- | --- |
| `companions/` | 十位伙伴档案、生产规则与图集合同 | 修改伙伴展示、对话、美术或羁绊前 |
| `systems/expedition/` | 远征掉落与地点相关规则 | 调整远征、结算、物品或掉落前 |
| `systems/post-office/` | 邮局生命周期、信件规则与视觉方案 | 修改邮局、AI 信件或来信节奏前 |
| `art/` | 总体美术规范、炉火小屋与邮局素材提示 | 制作或接入美术资产前 |
| `development/` | 音频接入与开发说明 | 接入本地音频或维护开发环境时 |
| `archive/` | 已结束的垂直切片与历史回归交接 | 仅用于追溯，不作为当前实现依据 |

## 暂停内容

根目录中所有 `TOWN_*.md` 以及对应小镇草稿均为**暂停材料**：不得移动、修改、接入或提交，除非用户明确重新授权。

## 变更规则

- 改动世界设定、伙伴生态位或羁绊阈值前，先以世界圣经和伙伴档案复核。
- 新功能必须服务于开始专注、保护专注、承认真实学习或增强长期归属，不能将伙伴变成数值工具。
- 过期的记录放入 `archive/`，不要与当前规格混用。
