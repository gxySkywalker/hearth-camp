# 炉火小屋 512×288 布局规格

状态：512×288 底图已接入候选资源；等待前景遮挡层与炉火动画。

## 1. 画布与视觉边界

- 逻辑画布固定为 `512×288`，16:9，采用 `32px` 网格（16 列 × 9 行）。
- 像素画只按整数倍缩放，最近邻采样；不得把现有 `320×180` 临时背景拉伸为新画布。
- 环境分为底图、可遮挡家具裁片、角色层和前景光效层。主角与伙伴永远由运行时叠加，不能烘焙在背景中。
- 家具遮挡不依赖单独生成的透明图：运行时从底图裁出日志桌、制图桌、宝箱、床脚与门槛的前沿，按角色脚底纵深排序。
- 炉膛底图保持空置；火焰使用独立透明 `4` 帧循环层，便于未来替换而不改动小屋结构。

## 3. 碰撞与角色规则

- 所有家具使用矩形碰撞体；中央活动区的连续可走动面积不得低于 `192×128`。
- 门槛只在中央出口处可通过，其余南墙阻挡角色。
- 伙伴默认跟随主角，不可作为阻挡物；“原地等待”是可逆的本地场景状态。
- 喂食入口只有在背包存在真实可喂食物品时才显示；本规格不定义食物、数值收益或羁绊阈值。
