# v0.8.5 - 星轨、诗集与旅途修缮

天文台重新校准每一段真实专注，吟游诗集添上二十页新的旅途赠诗；置顶小窗、小天使来信与炉火小屋也完成了一轮可靠性修缮。

## 🔭 天文台与真实专注

- 小时星轨统一使用存档中的真实有效专注时长，主动休息不会被计入。
- 修复跨午夜远征重复落入次日零点、造成单小时超过 60 分钟的问题。
- 日、周星图统一统计口径，并新增按自然日展示的「本月星向」柱状图。
- 月度纵轴直接显示分钟与小时，可切换前后月份回看真实投入。

## 📖 吟游诗集

- 新增 20 首符合炉火营地价值观的中外诗句，诗集由 20 首扩充至 40 首。
- 每首诗均附出处与旅途寄语；外文诗保留原文并注明项目自译或校订信息。
- 吟游诗人仍只会从尚未获得的诗中赠送一首，不会重复。
- 重做小屋图书柜诗集：增加星夜卷首、暖色纸页、页码、获得日期与译文说明。
- 英文诗恢复自然分行，不再使用斜杠模拟换行；空诗集也有完整的世界观引导。

## ✉️ 小天使 AI 来信

- 延长正式每日／每周来信的生成等待时间，降低长正文因超时退回模板的情况。
- DeepSeek 使用当前 OpenAI 兼容接口，连接试写与正式来信保持同一配置链路。
- 增加单实例队列、续跑保护与有限重试，避免多个入口重复消耗同一封信的生成次数。
- 邮局打开信件后会短时追踪后台润色结果；正文完成时可自动替换模板。
- AI 测试只使用临时数据库与模拟服务，不读取玩家 API Key 或真实存档。

## ⏱️ 远征规划与置顶小窗

- 远征时长改为 1–180 分钟自由设置，并使用像素刻度盘与五分钟步进微调。
- 置顶小窗放大路标与计时数字，新增「炉火原色」「夜行暗色」「羊皮纸白」三种高对比主题。
- 小窗主题写入本地设置，跨页面与重启均会保留。
- 小屋诗集与背包支持 `Esc` 逐层合上，不会误触发角色移动或全局返回。

## 🔊 小屋环境与伙伴营地

- 更换炉火环境音，并确保它只在炉火小屋内、炉火实际燃烧时播放。
- 提高木地板与地毯脚步反馈，炉火与脚步可以自然叠加。
- 伙伴图鉴固定展示初始形态、初始名字与真实物种，不再混用成长名。
- 共同背包增加像素风分页，可以完整浏览全部物品。

## 🧰 稳定性与升级说明

- 260 项自动化测试通过。
- 美术资源清单校验通过。
- Windows 生产构建与 NSIS 安装包验证通过。
- 保持既有应用标识与用户数据目录；覆盖安装不会清空伙伴、背包、诗集、旅途、信件、API Key 或自定义 BGM。
- 小镇原型仍处于暂停的本地草稿阶段，本版本没有接入或发布任何小镇内容。
