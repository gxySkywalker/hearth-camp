# 炉火营地 v0.8.1 · 公开测试修复与体验优化版

> 炉火仍在，旅途的记录也会被好好留住。

这是面向 Windows 公开测试用户的稳定性与体验更新。可直接覆盖安装 v0.8.0 或此前的 v0.8.1：应用标识与本地存档位置保持不变，不会删除、重置或上传你的任何记录。

## 下载

- **Windows 10 / 11（64 位）**：下载本页 Assets 中的 `Hearth-Camp-Setup-0.8.1.exe`。
- 安装时选择「仅为我安装」即可，无需管理员权限；桌面与开始菜单快捷方式都会指向当前用户的实际安装目录。
- 已安装 v0.8.0 的用户可直接运行新安装包并覆盖升级；存档、背包、伙伴、诗集和本地 BGM 包都会保留。
- 新用户安装后即可听到炉火小屋与远征的初始音乐；如果放入自己的 `cottage.mp3` 或 `expedition.mp3`，本地音乐会优先播放。

## 本次修复

- 两首初始 BGM 已随安装包提供，不再需要先配置音乐才能拥有完整氛围。
- 初始伙伴在每个成长阶段都始终显示为「栗子」，玩家手动命名则永久保留。
- 路标说明会在制图桌中直接可见，长知识遗物内容会在旅途总览中正常换行。
- 修复空背包乱码。
- 专注期间隐藏主窗口时，屏幕顶部会显示像素风置顶计时窗；点击即可回到炉火营地。
- 点击最小化「-」也会显示置顶计时窗，和关闭「×」的行为保持一致。
- 置顶窗可自由拖动、单独关闭，并会保持在浏览器、文档等普通应用窗口之上。
- 置顶窗已重绘为像素仪表盘；标题、状态和计时数字均随包使用 Fusion Pixel 字体，与主页面保持一致。
- 新旅人的初始称呼统一为「冒险者」；仅「学习者」与 `Traveler` 两个历史占位名会在升级时自动迁移，任何玩家自定义名字都会保留。
- 修复旧远征快照与当前昵称不一致时，把「栗子」和「炉尾」误写成两位同行的问题；后续信件始终使用当前伙伴昵称。
- 优化小天使 AI 来信的事实约束：没有真实记录就不补写伙伴动作、地点画面或并列同行，信件会围绕一条真实旅途记录连贯表达。
- 修复「请小天使试写一封信」可能出现空响应的问题：试写现为独立连通性检查，并兼容分段式 OpenAI 兼容响应；正式每日信会从真实出征次数和主要旅途方向自然起笔。
- 安装器会自动清除指向不存在目录的旧安装位置记录，并显式创建桌面与开始菜单快捷方式，修复快捷方式可能错误指向构建环境用户目录的问题；覆盖升级不需要管理员权限。

## 旅人形象

- 「旅人手册」中现可选择三位不同风格的冒险者：炉火旅人、青蓝旅人与金穗旅人。
- 形象选择只改变小屋中的外观，不改变名字、伙伴、背包、诗集或任何旅途记录。
- 青蓝旅人与金穗旅人的四向行走图已重新裁切，尺寸与炉火旅人统一，并移除生成图留下的棋盘底纹和白边。

## 邮局验证

- 每日、每周、节日与生日信件的创建、去重和本地模板降级均已在隔离数据库中自动验证。
- AI 信件仍完全可选。未填写 API Key 时邮局正常使用本地模板；填写后可以在应用内使用「请小天使试写一封信」验证真实网络连通性。Key 只保存在 Windows 安全凭据中，不会写入存档或安装包。
