# 山谷蜜熊伙伴档案 v1.0

## 身份与生态位

- 物种：山谷蜜熊
- 成长链：小蜜熊 → 暖掌熊 → 岩蜜守熊
- 栖息环境：向阳山谷、野蜂林与松果坡
- 专属纪念物：蜜蜡松果
- 最终成长模式：单一路线

山谷蜜熊代表“可以被捧在掌心、也能慢慢沉淀成安稳依靠的温暖”。它不会采蜜、生产资源、提高效率或参与战斗；名字中的“守”指陪伴与守候，不是防御属性。

## 识别语言

- 核心身体符号：圆耳、厚实前掌、短尾、额头与胸前的蜜色纹样；最终形态拥有岩层般的背部厚毛。
- 核心动作：用前掌拢住松果或晒暖的小物件，疲惫时靠着安稳的位置坐下。
- 情感关键词：温暖、承接、安稳、不催促。
- 与既有伙伴的区别：不使用栗子的犬型旧路与归途语言，也不使用石铁獾的石阶维护和秩序生态位；岩层背毛只表现沉稳体量。

## 成长含义

- 小蜜熊：会主动靠近暖意，也愿意把喜欢的小东西拢在身边。
- 暖掌熊：学会把掌心的温度分给同行的人。
- 岩蜜守熊：共同走过的温暖沉淀成安稳而克制的守候。

三种形态不改变掉落、效率、羁绊速度或任何强度数值。

## 美术资产

- 每种形态保存透明原始肖像与 4×4 四向源图。
- 运行时输出 32×32 紧凑 UI 图集及 48×48 Pixi 小屋图集。
- 行顺序固定为 front、back、left、right，每行四帧，共用脚底基线。
