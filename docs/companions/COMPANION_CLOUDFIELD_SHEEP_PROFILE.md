# 云野绵羊伙伴档案 v1.0

## 身份与生态位

- 物种：云野绵羊
- 成长链：咩咩 → 咩咩羊 → 晨风绵羊
- 栖息环境：晨雾高野、缓风牧坡与云影草甸
- 专属纪念物：旧牧铃穗
- 最终成长模式：单一路线

云野绵羊代表“休息以后仍然可以重新开始的温柔”。它不会产出羊毛、加快任务、提高收益或参与战斗；晨风只是一种陪伴意象，不提供速度属性。

## 识别语言

- 核心身体符号：卷云额毛、短角、垂耳、蓬松短尾与奶白色层叠卷毛。
- 核心动作：在晨风里轻轻抖开卷毛，听见旧铃声时停下脚步回望。
- 情感关键词：柔软、复原、清晨、重新出发。
- 与既有伙伴的区别：不使用云丘兔的丘陵远望与风茸语言，也不使用暮羽子的夜色守望；它专注于清晨、休息后的复原和不带催促的启程。

## 成长含义

- 咩咩：愿意亲近安静的人，也会在陌生草坡上小心地听风。
- 咩咩羊：开始记得同行者的脚步，并在疲惫时主动靠近。
- 晨风绵羊：把共同度过的清晨留在长绒里，陪人温柔地重新出发。

三种形态不改变掉落、效率、羁绊速度或任何强度数值。

## 美术资产

- 每种形态保存透明原始肖像与 4×4 四向源图。
- 运行时输出 32×32 紧凑 UI 图集及 48×48 Pixi 小屋图集。
- 行顺序固定为 front、back、left、right，每行四帧，共用脚底基线。
