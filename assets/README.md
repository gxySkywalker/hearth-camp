# 资源目录索引

| 目录 | 内容 |
| --- | --- |
| `branding/` | 应用图标与其确认后的原始来源图；运行时正式图标为 `app-icon.png` |
| `art/characters/` | 主角与伙伴的运行时精灵和肖像 |
| `art/environments/` | 小屋、远征等环境运行时资源；小镇内容保持暂停 |
| `art/drafts/` | 源草稿与尚未接入的美术探索，不能直接作为发布资源 |
| `art/reference/` | 用户确认过的美术参考原图 |
| `audio/` | 用户本地放置的 BGM 与音效；详见 `docs/development/AUDIO_GUIDE.md` |
| `fonts/` | 字体许可与字体资源 |
